\# 🏋️ Gym Membership Management System



A SQL-based database management system developed for efficiently managing gym operations including memberships, trainers, plans, payments, and reports.



\## 📌 Project Overview



This project is designed using MySQL and DBMS concepts to automate gym management activities.  

It includes member management, trainer records, membership plans, payment tracking, reports, views, joins, stored procedures, and analytical queries.



\## ✨ Features



\- Manage gym members

\- Store trainer details

\- Membership plan management

\- Payment tracking system

\- Revenue analysis

\- SQL joins and subqueries

\- Views and stored procedures

\- Reports and analytics



\## 🛠️ Technologies Used



\- MySQL

\- SQL

\- DBMS Concepts



\## 📂 Database Tables



\### Members

Stores member information including:

\- Member ID

\- Name

\- Email

\- Phone Number

\- Join Date



\### Trainers

Stores trainer details and specialization.



\### Plans

Contains membership plans with duration and pricing.



\### Memberships

Links members with plans using foreign keys.



\### Payments

Stores payment records and payment status.
